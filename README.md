# Метр. Каталог недвижимости

Учебное веб-приложение по индивидуальному заданию № 29. Браузер работает с Apache и PHP через HTTP. PHP хранит пользователей, объекты, фотографии, заявки, статусы, настройки и избранное в семи таблицах MySQL. В начальный каталог входят девять вымышленных предложений Москвы и области.

## Запуск в Windows

1. Распакуйте **весь архив** в папку с правом записи и запустите **Start.cmd**. В комплект входят Apache 2.4, PHP 8.4 и MySQL 8.4 для Windows x64. На новом компьютере может потребоваться Microsoft Visual C++ Redistributable x64.
2. При первом запуске создаются локальная база и учебные записи. После запуска откроется [каталог](http://127.0.0.1:8092/).
3. Откройте `storage/access.txt` в распакованной папке. В нём указаны адреса для всех ролей и случайный пароль этой установки. Нажмите **Войти** в правом верхнем углу сайта. Новый посетитель также может самостоятельно зарегистрироваться как клиент.
4. Для остановки обоих серверов запустите **Stop.cmd**. Следующий запуск **Start.cmd** сохранит изменения.

Стенд слушает только локальные адреса. Apache занимает порт 8092, MySQL — 33429. Если порт занят другой программой, скрипт сообщит об этом. Для другой пары портов укажите `-WebPort` и `-DbPort` при первом ручном запуске `bin/stand.ps1` и используйте те же параметры для последующих запусков и остановки. Дополнительный ключ `-NoBrowser` отключает открытие вкладки.

## Сценарий для защиты

| Роль | Учебный логин | Что показать |
| --- | --- | --- |
| Агент | agent@metr.test | Создать объект, заполнить адрес, цену, площадь, описание и приложить JPEG или PNG. Отправить карточку на проверку. |
| Модератор | moderator@metr.test | Открыть очередь, при необходимости исправить карточку и фотографии. Опубликовать объект или вернуть агенту с причиной. |
| Клиент | client@metr.test | Найти опубликованный объект по названию и цене, сохранить его сердечком, открыть карточку из раздела «Избранное», указать телефон и решить проверочный пример. |
| Агент | agent@metr.test | В разделе «Заявки» взять обращение в работу и завершить его. |
| Администратор | admin@metr.test | Посмотреть дату и время последнего входа, изменить доступ или удалить пользователя. Передать объекты другому агенту, изменить название статуса или размер страницы каталога. |

Изменение карточки или фотографий отправляет объект на повторную проверку. Пока модератор не одобрил новую версию, объявление и его снимки скрыты из общего каталога. Агент может удалить свою карточку на проверке или после отклонения, если по ней ещё нет заявок. Архивирование сохраняет историю. Блокировка учётной записи прекращает доступ к кабинету.

## Устройство проекта

- `public/` — единственная открытая папка Apache. Входной файл — `index.php`. Интерфейс работает на HTML, CSS и JavaScript.
- `modules/` — каталог, авторизация, объекты и фото, заявки, модерация, администрирование и сборка данных кабинета.
- `templates/app.php` — HTML страницы. Заполняемые пользователем данные экранируются перед выводом.
- `database/schema.sql` — таблицы MySQL, внешние ключи, индексы, статусы и начальные настройки. Уникальный индекс по клиенту, объекту и признаку открытой заявки предотвращает повтор в параллельных запросах.
- `config/database.php` — соединение PDO. Включены настоящие подготовленные запросы. Рабочая учётная запись базы имеет только права чтения и изменения данных.
- `storage/photos/` — изображения со случайными именами. PHP сверяет содержимое, формат, вес и размеры, декодирует и повторно сохраняет снимок в JPEG. Максимум 8 фото на карточку, по 5 МБ и 16 Мп на входе. После обработки длинная сторона составляет до 1600 пикселей. Права на просмотр проверяются при выдаче каждого файла.
- `storage/sessions/`, `storage/logs/` — сеансы и журналы. Пароли пользователей хешируются. Для изменяющих запросов проверяется CSRF-токен. Проверочное задание заявки действует пять минут и используется один раз. Между успешными заявками клиента должно пройти 30 секунд.
- `storage/stand/` — данные автономной установки Windows. В этой папке находятся закрытые параметры подключения и файлы MySQL.
- `bin/`, `demo/`, `runtime/` — запуск и инициализация, исходные иллюстрации учебных объявлений и комплект серверных программ.

## Установка на существующий Apache и MySQL

При обновлении уже установленного вручную каталога выполните в его базе недостающие миграции из `database/migrations/` по порядку. Файл `001_favorites.sql` добавляет избранное, `002_request_client.sql` позволяет сохранять заявки после удаления учётной записи клиента, а `003_last_login.sql` добавляет время последнего входа. В автономном комплекте Windows обновления базы выполняются при запуске `Start.cmd`.

Для собственного сервера используйте PHP 8.2 или новее с расширениями pdo_mysql, mbstring, fileinfo и GD и MySQL 8.0.16 или новее. Настройте Apache DocumentRoot на абсолютный путь к `public` и включите обработку `.php`. Создайте базу `metr` с кодировкой utf8mb4, импортируйте `database/schema.sql` и назначьте отдельному пользователю права SELECT, INSERT, UPDATE и DELETE на эту базу. Задайте DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD в окружении Apache и PHP CLI или создайте `config/local.php`, возвращающий массив с этими ключами.

Предоставьте процессу PHP право записи в `storage/photos`, `storage/sessions` и `storage/logs`. Установите `upload_max_filesize=5M`, `post_max_size=42M` и `memory_limit=256M`. Выполните `php bin/seed.php` для заполнения пустой базы и создания учебных учётных записей. Файл с реквизитами создаётся вне открытой папки сайта.

## Сохранение и восстановление

Для автономной версии Windows запустите **Stop.cmd** и дождитесь завершения. Скопируйте папку проекта целиком на носитель резервной копии. Так база, ключи доступа и фотографии относятся к одной точке времени. Храните эту копию как закрытую, поскольку в ней есть контакты из заявок.

Для восстановления скопируйте сохранённую папку в новое расположение с правом записи. При выключенном прежнем стенде запустите **Start.cmd** из восстановленной папки. Откройте известную карточку с фотографией и проверьте связанную заявку в кабинете агента. На самостоятельно настроенном сервере сохраняйте дамп MySQL вместе с `storage/photos`, приостановив на время копирования операции записи приложения.

## Результаты проверки

На локальном стенде Windows проверены интерфейс при ширине 1440 и 390 пикселей, регистрация и вход, переходы по всем четырём кабинетам и цикл от загрузки фото до завершения заявки. Дополнительно проверены отклонение повреждённого снимка, уменьшение большого фото, запрет изменения чужой карточки, отказ при устаревшей версии, повторная модерация, передача между агентами, блокировка пользователя, удаление и архивирование.

В двух независимых сеансах одного клиента при одновременной подаче двух обращений база сохранила одну открытую заявку. Неверный и повторно использованный ответ CAPTCHA отклонены. Из дампа отдельной испытательной базы и копии фотографий восстановлены связанные данные заявки и 10 изображений, контрольные суммы изображений совпали.

Для оценки поиска использовалась отдельная база из 10 000 объектов и 20 одновременно работающих клиентских сеансов. Выполнено 400 HTTP-запросов с фильтрацией, сортировкой и пагинацией. 95-й процентиль времени получения и чтения JSON-ответа составил 101 мс, максимум — 323 мс. Все 400 запросов уложились в 2 секунды. Измерения относятся к этой машине и локальному подключению.

Фотографии из Unsplash используются как иллюстрации учебных объявлений. Адреса, цены и описания демонстрационные. Изображения включены в архив для работы без интернета.
